# webui

Contains the **Stickman Video Director** skill (MIT, from https://github.com/kaomei/stickman-video-director, commit 99f0cc0),
installed at `.claude/skills/directing-stickman-videos`.

Any Claude Code session opened on this repo (including from the Claude app on a phone, via the Code tab)
picks the skill up automatically. Try:

> Use Director Mode / mode A to turn this topic into a 30-second stickman video: [topic]. Landscape 16:9, A3 "Prehistoric Cave" style. Give me the director's treatment first.
